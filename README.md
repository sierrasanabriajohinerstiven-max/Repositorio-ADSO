# Marichuy - E-commerce Platform

Plataforma de comercio electrónico para la venta de chocolates y productos artesanales "Marichuy".

## Características
- Catálogo de productos.
- Carrito de compras.
- Integración de pagos con Nequi (manual mediante comprobante).
- Panel de administración para gestión de pedidos y productos.
- Generación automática de recibos en PDF.
- Notificaciones por correo electrónico.

## Tecnologías
- Python / Flask
- Flask-SQLAlchemy (Base de datos)
- Jinja2 (Templates)
- Vanilla CSS / HTML
- ReportLab (PDF)

## Instalación
1. Clonar el repositorio.
2. Crear un entorno virtual: `python -m venv venv`
3. Activar el entorno virtual.
4. Instalar dependencias: `pip install -r requirements.txt`
5. Ejecutar la aplicación: `python run.py`
